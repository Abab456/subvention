# Subvention Énergie — Québec

Independent Québec energy-efficiency financial assistance discovery and application-support concept.

## Status
**Validation-stage repository, not a production grant estimator.** The next deliverable is an interactive mockup and a verifiable program-rule assessment, for founder review before committing to a full build.

## Overnight two-agent work
Read `AGENTS.md` and `docs/overnight-brief.md`. Project-scoped Codex roles live in `.codex/agents/`.

- `experience_builder`: French-first clickable validation mockup (`prototype/`).
- `program_rules`: source-grounded Québec program inventory, rule contract, and safe calculation/test scaffold (`docs/programs/`, `engine/`).

Run the roles from a live Codex session with a supervising coordinator, in separate worktrees/branches when possible. **These files do not start any agent automatically.**

## Hard boundaries
No live grants quoted without verified rules, no real customer files, no live payments, no government submission, no automatic deployment, and no merge to main without review.

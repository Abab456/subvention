The multiresidential path deliberately does not choose a residential-versus-business classification from unit count alone. Large, mixed-use and unusual buildings need a scoped manual review; the current engine does not claim complete funding coverage for them. Municipal, gas-distributor, income-targeted, adaptation and other specialized programs are outside this initial catalog. `no_covered_match` never means no assistance exists.

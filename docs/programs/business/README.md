This is an initial landscape, not an exhaustive funding search. Municipal incentives, other provincial streams, tax credits, financing, federal industrial programs and sector-specific calls require separate review. Financing and tax credits must not be silently presented as grants. Demand, profitability and “best market” claims have not been validated; see `market-priorities.md`.
